The Factorization Machine on the NASA logs

How to read this page. The task is supervised binary classification with 2 classes, normal and attack (SQL injection, XSS, command injection, path traversal). Models learn from labelled public datasets (HttpParams, Fwaf), because the NASA logs have no labels. F1 balances precision (when the model says "attack", how often it is right) and recall (how many real attacks it catches); accuracy alone is misleading when 97% of requests are normal.
