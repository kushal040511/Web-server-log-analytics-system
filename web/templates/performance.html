A note on what "performance" means here. NCSA Common Log Format has no response-time field, so this page measures response weight in bytes, not latency. That is still the right lever for bandwidth cost, and it is honest about what the data supports. On a live Nginx server you would add $request_time to the log format; the parsing regex gains one field and every chart here would gain a latency twin.
